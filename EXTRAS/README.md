# EXTRAS Directory

This directory contains research writeups, IEEE/ACM publication manuscripts, historical evaluation dossiers, execution logs, test reports, and archived submission files. These files were created during testing, benchmarking, and paper preparation, and have been moved out of the project root to keep the core software repository clean and focused on runnable functionality.
